# MSc Medical Physics Dissertation – Evoked Potential Analysis

This repository contains the Python scripts developed and used for data analysis as part of the MSc Medical Physics dissertation:

**Analysing Different Evoked Potentials Across Subjects of Different Ages**

## Contents

- `VEP_Trace_Level_Analysis.py` – Trace-level processing and analysis of visual evoked potential (VEP) recordings.
- `VEP_Statistical_Analysis.py` – Statistical analysis of VEP results.
- `SSEP_Analysis.py` – Analysis of somatosensory evoked potential (SSEP) results.
- `BAEP_Analysis.py` – Analysis of brainstem auditory evoked potential (BAEP) results.
